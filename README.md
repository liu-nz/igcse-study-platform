# IGCSE 智能备考平台

一款面向 IGCSE 考生的一站式智能备考网站，支持资料管理、刷题练习、智能复习、AI 问答、好友协作等功能。

## 功能特性

8大科目题库（数学/物理/化学/生物/经济/英语ESL/ICT/计算机科学），80道练习题，56张闪卡，14份资料，14套真题，10个AI知识点。

纯前端实现，零依赖，打开即用。响应式设计适配手机和电脑端。
